# Origins Unknown — iainreid.dev

The live site for Origins Unknown: a history of remote viewing and astral projection and their overlap, and the Seeds of the Throne story it feeds.

The site is one self-contained `index.html` (all ten pages, hash-routed) plus `favicon.svg`. Deployment: cPanel Git Version Control clones this repo on the hosting account and `.cpanel.yml` copies the two files into `~/public_html/origins-unknown/`. The domain root redirects there.
